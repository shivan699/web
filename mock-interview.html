💻 Technical Questions

What are the four pillars of OOP?
1. Encapsulation — hiding data via access modifiers
2. Inheritance — child class gets parent properties
3. Polymorphism — one method, different behaviors
4. Abstraction — hiding complexity
👆 Click to reveal
What is the difference between == and .equals() in Java?
== compares object references (memory addresses). .equals() compares the actual content/value of objects. Always use .equals() for string comparison.
👆 Click to reveal
What is a REST API? Name the HTTP methods.
REST is an architectural style using HTTP for data communication. Methods: GET (read), POST (create), PUT (update), DELETE (remove), PATCH (partial update).
👆 Click to reveal
What is the difference between ArrayList and LinkedList?
ArrayList: array-backed, fast access O(1), slow insert/delete O(n).
LinkedList: node-based, slow access O(n), fast insert/delete O(1) at ends.
👆 Click to reveal
What is a SQL INNER JOIN?
Returns only rows where there is a match in both tables.
SELECT * FROM A INNER JOIN B ON A.id = B.a_id
👆 Click to reveal
What is Big O notation?
Big O describes algorithm efficiency. O(1)=constant, O(log n)=logarithmic, O(n)=linear, O(n²)=quadratic. Lower is better. Used to compare algorithms.

☁️ ServiceNow Questions

What is ServiceNow?
ServiceNow is a cloud-based platform for IT Service Management (ITSM). It helps organizations automate digital workflows, manage IT operations, and track incidents, problems, and changes.
👆 Click to reveal
What is a Business Rule in ServiceNow?
A server-side script that runs automatically when a record is inserted, updated, deleted, or queried. Used to enforce business logic, update fields, or trigger actions.
👆 Click to reveal
What is GlideRecord?
GlideRecord is the primary API to query and manipulate ServiceNow database tables via server-side scripts. Example:
var gr = new GlideRecord('incident'); gr.query();
👆 Click to reveal
Difference between Client Script and Business Rule?
Client Script: Runs in the browser. Controls form behavior (show/hide fields, validate input).
Business Rule: Runs on the server. Enforces data logic when records are saved.
👆 Click to reveal
What is a UI Policy in ServiceNow?
UI Policy controls form behavior (make fields mandatory, read-only, visible) without writing scripts. It's a no-code alternative to Client Scripts for simple field rules.
👆 Click to reveal
What is the CMDB?
CMDB (Configuration Management Database) stores information about IT assets (Configuration Items / CIs) and their relationships. Helps in impact analysis and root cause analysis.
