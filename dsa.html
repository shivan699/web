📦 Array Challenges
Find the Largest Element
Find the maximum value in an array of integers.
EasyArrays • O(n)
// Java Solution int max = arr[0]; for(int i = 1; i < arr.length; i++){ if(arr[i] > max) max = arr[i]; } System.out.println("Max: " + max);
Two Sum Problem
Given an array, find two numbers that add up to a target.
EasyHashMap • O(n)
// Java - HashMap approach Map<Integer,Integer> map = new HashMap<>(); for(int i = 0; i < nums.length; i++){ int comp = target - nums[i]; if(map.containsKey(comp)) return new int[]{map.get(comp), i}; map.put(nums[i], i); }
Rotate Array by K Positions
Rotate an array to the right by k steps efficiently.
MediumArrays • O(n)
// Reverse approach void rotate(int[] nums, int k){ k %= nums.length; reverse(nums, 0, nums.length-1); reverse(nums, 0, k-1); reverse(nums, k, nums.length-1); }
Find Duplicate in Array
Array of 1–n integers has one duplicate. Find it.
MediumMath • O(n)
// Sum formula approach int n = arr.length - 1; int expected = n * (n+1) / 2; int actual = 0; for(int x : arr) actual += x; return actual - expected; // = duplicate
Kadane's Algorithm (Max Subarray)
Find the contiguous subarray with the maximum sum.
HardDP • O(n)
int maxSum = arr[0], curSum = arr[0]; for(int i = 1; i < arr.length; i++){ curSum = Math.max(arr[i], curSum + arr[i]); maxSum = Math.max(maxSum, curSum); } return maxSum;
🔤 String Challenges
Palindrome Check
Check if a given string is a palindrome.
EasyStrings • O(n)
// Python one-liner def isPalindrome(s): s = s.lower().replace(" ", "") return s == s[::-1] // Java String rev = new StringBuilder(s).reverse().toString(); return s.equals(rev);
Anagram Check
Determine if two strings are anagrams of each other.
EasySorting • O(n log n)
// Java - Sort and Compare char[] a1 = s1.toCharArray(); char[] a2 = s2.toCharArray(); Arrays.sort(a1); Arrays.sort(a2); return Arrays.equals(a1, a2);
Longest Common Prefix
Find the longest common prefix string among an array of strings.
MediumStrings • O(n*m)
String prefix = strs[0]; for(String s : strs){ while(!s.startsWith(prefix)) prefix = prefix.substring(0, prefix.length()-1); } return prefix;

Valid Parentheses
Check if string of brackets is properly balanced using a stack.
EasyStack • O(n)
Stack<Character> stack = new Stack<>(); for(char c : s.toCharArray()){ if(c=='('||c=='['||c=='{') stack.push(c); else { if(stack.isEmpty()) return false; char top = stack.pop(); if(c==')' && top!='(') return false; if(c==']' && top!='[') return false; if(c=='}' && top!='{') return false; } } return stack.isEmpty();
Implement Queue using Stacks
Implement FIFO queue using only two stacks.
MediumStack • Classic
// Use two stacks: s1 (push), s2 (pop) void enqueue(int x){ s1.push(x); } int dequeue(){ if(s2.isEmpty()) while(!s1.isEmpty()) s2.push(s1.pop()); return s2.pop(); }
